# Changelog

All notable changes to **Effect Pause** are documented here.

## [0.2.0] - 2026-09-14

- Added Foundry VTT v14 Active Effect duration support.
- Added separate Foundry v13 and v14 pause/resume handling for their different Active Effect schemas.
- Supports the default D&D5e actor sheet and Tidy 5e Sheets.
- Supports Foundry VTT v13-v14 and D&D5e 5.2.5-5.3.3.

## [0.1.2] - 2026-09-14

- Increased the clickable area of the pause/resume control on the default D&D5e sheet.
- Added spacing between Effect Pause and native sheet controls to reduce accidental clicks.

## [0.1.1] - 2026-09-14

- Fixed pause-button alignment on the default D&D5e sheet by using the sheet's native control structure.
- Kept Tidy/fallback styling separate.

## [0.1.0] - 2026-09-14

- Initial module version for Foundry VTT v13.
- Added pause/resume controls for supported world-time Active Effects.
